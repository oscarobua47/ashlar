# Goldens

These `{input, expected}` JSON files were generated by `mcp-server/tools/goldens.mjs` (now
deleted) running against the TypeScript implementation at commit `a56c582` (step 7.2a: "Plugin:
model-facing text formatting ported to Java with cross-language goldens").
