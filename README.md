## ✨ What Is Ashlar?

Ashlar is a bridge between your Minecraft server and AI assistants. It lets AI tools like Claude, ChatGPT, and Cursor connect directly to your Paper server. The AI can look at your world, place blocks, build structures, and check what is happening in real time.

Think of it as giving a smart robot access to your Minecraft world. You describe what you want ("build a castle entrance"), and the AI uses Ashlar to do it for you. No coding, no command blocks, just plain language.

Ashlar needs three things to work:

### 1. 🎮 A Minecraft Paper Server
- You need a Paper server (version 1.20.4 or newer recommended)
- If you do not have one, search "how to set up a Paper Minecraft server on Windows" — plenty of easy guides exist
- Your server should be running while you use Ashlar

### 2. 🧠 An AI Assistant

- Make sure you have one of these installed and logged in

### 3. 🔌 A Connection Between Them
- Ashlar acts as the middle-man
- It provides a link (MCP endpoint) that your AI assistant connects to
- Follow the on-screen instructions in Ashlar for the exact address

## 📝 How to Use Ashlar (Simple Example)

**Step 1:** Start your Minecraft Paper server.

**Step 2:** Open Ashlar on your computer. It will show you a connection URL (something like `http://localhost:3456`).

**Step 3:** In your AI assistant, open the MCP settings or add a new server connection.

**Step 4:** Paste the URL from Ashlar into the MCP connection field.

**Step 5:** Save and connect. You should see a green "Connected" indicator.

**Step 6:** In the AI chat, type something like:
> *"Look at the area near my player. Build a small stone bridge across the river, 3 blocks wide."*

The AI will survey, plan, and build it automatically on your live server.

## 🆘 Troubleshooting

**Problem: AI says "Cannot connect"**
- Check the link is still running
- Make sure your Paper server is online
- Restart both Ashlar and your AI assistant

**Problem: Builds are in wrong location**
- Ask the AI to "survey the area" first so it sees the correct coordinates
- Be clear about where you want the build (e.g., "next to the blacksmith shop", "north of spawn")

**Problem: No blocks appear**
- Confirm you are on a Paper server (not a vanilla server)
- Check the server has `enable-command-block=true` in `server.properties`
- Restart the server after making changes
